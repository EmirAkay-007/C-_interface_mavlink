C#-based MAVLink UAV interface communicating with Pixhawk Orange Cube+. Displays live video processed via Jetson Orin NX & Raspberry Pi HQ camera, and tracks real-time location on a satellite map. It also handles bidirectional server communication to receive, process, and send data. ( With the contributions of Mr. Fatih AYIBASAN )
